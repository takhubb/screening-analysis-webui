# J-Quants Screening Analysis WebUI

`references` 配下のスクリーニングロジックを参考にしつつ、買いシグナル条件とフィルター指定から固定期間リターン分析までをブラウザで実行できる WebUI です。

## できること

- 出来高急増、高値更新などの買いシグナル条件を指定
- 対象市場、売買代金、時価総額、PER、PBR、自己資本比率、売上成長率、営業利益成長率、営業利益率などをスクリーニング条件として指定
- 指定期間内のシグナルを抽出
- スクリーニング銘柄をシグナル翌営業日の始値で100株購入し、3 / 6 / 9 / 12か月後の終値で評価したリターンを分析
- 3パターンのフィルター条件を同時に比較
- クールダウン後シグナルだけを対象に、全業種と業種別のリターン結果を集計
- count / mean / median / std / min / p10 / p25 / p75 / p90 / max / win_rate / sharpe / max_drawdown を CSV に出力
- 買いシグナル条件とスクリーニング条件を各行に含む結果 CSV を `output/` に作成

## 前提

- ルートの `.env` に `JQUANTS_API_KEY=...` が入っていること
- `references` は参照専用で、このアプリは変更しません

## 起動方法

```bash
docker compose up --build
```

起動後、ブラウザで `http://localhost:8501` を開いてください。

実行が完了すると、プロジェクト直下の `output/` に `cooldown_returns_...csv` が作成されます。
Web 画面には完了メッセージと出力先だけを表示し、結果の中身は CSV で確認します。

## 実装メモ

- 価格・銘柄マスタ・財務サマリは J-Quants の bulk を使って `.cache/jquants` にキャッシュします
- bulk の価格 CSV は調整後価格を持たないため、`AdjFactor` から `AdjC` / `AdjVo` を復元します
- リターンは調整後始値 / 調整後終値を使い、シグナル翌営業日の始値で100株購入して3 / 6 / 9 / 12か月後の最初に取得できる営業日終値で評価した前提で算出します
- 業種はスクリーニング条件には使わず、クールダウン後リターンの集計軸として使います
- 財務条件は `references/ten-bagger-screening` の考え方をベースに、シグナル日時点で利用可能な最新開示を `merge_asof` で結合します
